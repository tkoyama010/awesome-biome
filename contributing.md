# Contributing Guide

Thank you for your interest in contributing to this list! This document explains the contribution process.

## How to Contribute

1. Fork this repository
2. Create a new branch (`git checkout -b add-something`)
3. Make your changes
4. Commit your changes (`git commit -am 'Add something'`)
5. Push to the branch (`git push origin add-something`)
6. Create a Pull Request

## Guidelines

### Quality Standards

- Each item needs a description
- Both proprietary and open-source software is fine
- Keep the list alphabetically ordered
- Each item should be short and clear

### Pull Requests

- Each PR needs a clear title and description
- Explain what you changed concisely
- If removing existing items, explain why

### Format

```markdown
- [Project Name](URL) - Brief description.
```

### Categories

Add to the appropriate category:

- Official Resources
- Community
- Tools
- Editor Integration
- Configuration
- Tutorials and Articles
- Templates
- Other

## Before Contributing

- Make sure it's not already listed
- Make sure the link works
- Make sure there are no spelling mistakes

Thank you!
